# AI Resume Screener

## Live Demo

https://ai-resume-screener-nx7k.onrender.com

## Project Overview

AI Resume Screener is an AI-powered ATS Resume Screening system that helps recruiters compare resumes with job descriptions.

The application can:

- Upload PDF resumes
- Upload Job Descriptions
- Generate ATS Scores
- Extract Skills
- Rank Candidates
- Generate Candidate Reports
- Answer Resume Questions using AI Chatbot

---

## Features

### ATS Resume Scoring

Calculates how well a resume matches a job description.

### Skill Extraction

Automatically extracts candidate skills.

### Candidate Leaderboard

Ranks candidates according to ATS score.

### Candidate Reports

Displays candidate profile and ATS analysis.

### Resume Chatbot

Answers questions about uploaded resumes.

Examples:

- What are the candidate skills?
- Summarize the candidate.
- What technologies does the candidate know?
